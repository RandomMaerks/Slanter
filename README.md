# 🟩 Slanter

Slanter is a rigid condensed sans-serif typeface with slanted apertures and sharp corners, built to be displayed at a large size.

> [!WARNING]
> This is an early work-in-progress. I literally can't give a better description because this is only a prototype, but more words will be arriving as soon as I'm done with the design.
